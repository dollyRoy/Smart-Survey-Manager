# 🌍 Smart Survey Manager

A modern desktop-based surveying data management system built using **JavaFX** and **SQLite**.  
This application helps users efficiently manage, visualize, and analyze survey point data through an elegant and interactive dashboard UI.

---

# ✨ Features

## 📍 Point Management
- Add new survey points with:
  - Point ID
  - X Coordinate
  - Y Coordinate
  - Z Elevation
- Edit existing points
- Delete single or multiple points
- Clear all survey data instantly

---

## 📊 Smart Data Table
- Interactive table for managing survey points
- Multiple row selection support
- Real-time table updates
- Smooth UI animations and transitions

---

## 📏 Distance Calculator
Calculate distance between two survey points instantly using coordinate values.

### Supports:
- Point selection dropdowns
- Dynamic distance calculation
- Live result display

---

## 📈 Elevation Statistics Dashboard
Get instant elevation insights including:
- Highest elevation point
- Lowest elevation point
- Average elevation

Statistics update automatically whenever data changes.

---

## 📂 CSV Export
Export all survey data into a `.csv` file for:
- Reporting
- External analysis
- Backup purposes

---

## 🌙 Dark Mode Support
Modern light and dark themes with smooth switching for a professional dashboard experience.

---
